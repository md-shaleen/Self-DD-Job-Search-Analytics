# Self-DD — Job Search Analytics

## Overview
End-to-end analytics project analyzing 2,265 job applications 
across 6 countries, 50 companies, and 6 platforms using SQL and Power BI.

## Tools Used
- MySQL — data structuring and analysis
- Power BI — interactive dashboard and data modelling
- Excel — data preparation

## Files
- self_dd.pbix — Power BI dashboard (4 pages)
- job_search_analysis.sql — All SQL queries

## Project Summary
Built a star schema data model with Fact_Applications 
and dimension tables for Role, Company, Country, Platform and Resume.
Analyzed application trends, resume ATS performance, 
platform effectiveness, and outreach strategy.
